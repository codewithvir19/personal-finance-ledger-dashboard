# 💰 Personal Finance Ledger Dashboard

An interactive Personal Finance Dashboard that analyzes income, expenses, savings, and spending trends using data visualization.

## 🚀 Features
- Monthly Income vs Expense Analysis
- Spending by Category
- Top Merchant Analysis
- KPI Dashboard
- Search & Filter Transactions
- 3-Month Rolling Average Prediction
- Responsive Design

## 🛠️ Technologies
- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- Python
- JSON
- Data Analysis
- Data Visualization
